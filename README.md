# BTC 回测实验台

目标:在历史数据上验证交易策略,先让「单笔数学期望」稳定为正,再考虑实盘。
本项目只做现货、只做多、只用 1 小时 K 线。

## 快速开始

```powershell
cd btc-backtester
# 1. 下载历史数据(2019-11 至今,无需 API Key)
python fetch_data.py
# 2. 运行回测,输出绩效表 + 净值曲线图
python run_backtest.py
```

注:本机 Python 不含 matplotlib 时,依赖已安装在 `lib/` 目录,直接运行即可;
若在别的机器上运行,请先 `pip install -r requirements.txt`。


## 傻瓜式模拟盘控制台(推荐小白先用这个)

双击 `启动模拟盘.bat`,会自动打开浏览器控制面板,全程点按钮即可:

1. 点 `① 检查连接` —— 程序自动试 OKX,连不上就自动切 Gate.io(国内直连,不用VPN)。
2. 点 `② 保存并启动` —— 没填密钥 = 本地虚拟成交(推荐);填了 OKX 模拟盘密钥且 OKX 可达 = 模拟盘真实挂单(虚拟资金)。
3. 面板实时显示:网络/数据源/信号/余额/持仓/止损价,下面有价格曲线和红蓝买卖点。
4. `③ 停止` 随时暂停(状态自动保存,下次启动接着跑);`④ 退出程序` 关闭控制台。

- 策略与回测一致: SMA48/336 + 收盘>SMA1440 做多, 15% 固定止损, 每笔风险 1%, 只做多现货, 1 小时 K 线。
- 状态文件 `paper_state_okx.json`,成交明细 `paper_trades_okx.csv`(用来统计真实滑点)。
- 密钥只存在本机 `paper_config_okx.json`,不要填真实交易所密钥,只用"模拟盘"密钥。

## 实时行情 + 形态雷达

- 控制台首页新增「实时行情」卡片: 最新价、最近10分钟每笔成交曲线(秒级)、持仓浮盈亏、下次信号判断倒计时、本小时K线进度, 约3秒刷新一次。
- 「当前形态」识别(只用过去数据, 无未来函数): 瀑布/砸盘、拉盘、疑似洗盘、反弹、回调、盘整、疑似吸筹、大资金异动(疑似), 附白话解读与历史统计概率(非预测)。
- 「庄家入场」无法直接观测, 只能用异常放量做概率性代理, 一律标注"疑似"。
- 两个可选开关(默认关, 回测结论: 历史上不提高期望): 瀑布/砸盘自动离场、盘整/拉盘时暂停开仓。
- 形态规则回测: `python run_patterns_backtest.py`, 结果在 `results/pattern_backtest_*.csv` 与 `results/pattern_stats.csv`。

## 目录结构

- `config.py` — 手续费/滑点、样本切分(训练期/测试期)
- `fetch_data.py` — 下载 BTC/USDT 1h 历史数据(多数据源自动切换)
- `run_backtest.py` — 主入口:回测 + 报表 + 图表
- `backtest/engine.py` — 撮合引擎(下一根开盘成交、手续费滑点、止损/跟踪止损)
- `backtest/metrics.py` — 绩效指标(总收益、年化、回撤、夏普、胜率、盈亏比、单笔期望)
- `strategies/` — 策略库,每个策略返回 0/1 持仓信号
- `data/` — 行情数据 CSV
- `results/` — 绩效表 CSV 与净值曲线 PNG

## 核心指标怎么读

- 单笔期望(expectancy):平均每笔交易盈亏占投入本金的百分比,即「数学期望」。
- 盈亏比(profit factor):总盈利 / 总亏损,>1.2 才算稳健。
- 同期基准收益:买入持有的收益。策略必须能解释自己为什么优于"傻拿"。

## 防自欺的四条纪律(重要)

1. 只在训练期调参数;测试期(2025-01 起)只能用于最终验证。
2. 与买入持有基准比较:比特币长期向上,赢不过"傻拿"的策略没有存在意义。
3. 所有结果已计入手续费(0.1%/边)和滑点(0.05%/边)。
4. 警惕过拟合:参数越多、样本内越好的策略,样本外越容易翻车。
   相邻参数表现相近(如 24/336 与 48/336)比单一"神奇参数"更可信。

## 已内置策略(参数在训练期选定)

- 买入持有(基准)
- 双均线 48/336 + 15% 止损
- 趋势过滤 收盘>SMA1440(60日)+ 15% 止损
- 趋势系统 48/336 + 60日闸门 + 15% 止损
